## Technologies Used
- HTML5
- CSS3
- Google Fonts
- Visual Studio Code
- Git and GitHub

## Design Choices

### 1. Colour Palette
I selected dark teal, light green, white and
light blue colours.

Dark teal gives a professional appearance.
Light green makes the hero section look clean.
White provides a simple background for project cards.

### 2. Fonts
I used Poppins for headings because it looks
bold and modern.

I used DM Sans for body text because it is
clean and easy to read.

### 3. CSS Variables
I used :root variables to manage colours,
font sizes, spacing and border radius.

### 4. Hover Effects
I added hover effects to navigation links,
buttons, skill boxes and project cards.

### 5. Responsive Design
I used a CSS media query to make the
portfolio work on smaller screens.
